# Intersection

A free, installable daily trainer for five soft skills: asking questions, communication, execution, negotiation and sales.

- 120 techniques from primary sources, each with a lesson, two scenario quizzes, a written drill with a model answer, a spoken drill with a rubric, and a real-world mission
- 40 cross-skill "intersection" challenges
- About 280 sessions of new material, then Mastery mode, with spaced review throughout
- Voice: scenarios read aloud, answers recorded with playback, live transcript, pace and filler-word metrics
- Grading: auto-graded quizzes; written and spoken answers graded by Claude (in the Claude app for free, or instantly in-app with an optional API key)

Install: open the site in Safari on iPhone → Share → Add to Home Screen. Progress is stored on the device; use Settings → Copy backup now and then.
